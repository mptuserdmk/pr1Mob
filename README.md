# Практическая работа: Верстка базовых элементов пользовательского интерфейса (UI) во Flutter

**Оценка: 5 (Отлично)**  
Реализовано 4 полноценных макета (2 простых и 2 сложных) по мотивам дизайн-системы Figma.

---

## 📌 Описание проекта
Данный проект представляет собой учебную работу по мобильной разработке на фреймворке **Flutter** (язык Dart).  
Основная цель работы — освоение декларативного подхода к построению UI и изучение базовых виджетов Flutter.

Все экраны и логика навигации реализованы в одном файле: [`lib/main.dart`](file:///C:/dart/dart_application_1/lib/main.dart).

---

## 📱 Структура приложения и реализованные экраны

Приложение оснащено удобным главным экраном (`HomeScreen`) с нижней панелью навигации (`BottomNavigationBar`), разделенной на две вкладки:

### 1. Вкладка «Простые макеты» (2 экрана)
* **Макет 1: Экран профиля пользователя (`ProfileScreen`)**
  * Круглый аватар пользователя (`CircleAvatar`)
  * Текстовая информация: ФИО, статус, краткая биография (`Text`)
  * Кнопки действий: «Изменить» и «Поделиться» (`Row`, `ElevatedButton`, `OutlinedButton`)
  * Блок статистики: проекты, подписчики, подписки (`Card`, `Row`)
  * Контактные данные с иконками (`ListTile`, `Icon`)
  * Список тегов ключевых навыков (`Wrap`, `Chip`)
* **Макет 2: Экран авторизации и входа (`LoginScreen`)**
  * Фирменный логотип в скругленном контейнере (`Container`, `Icon`)
  * Текстовые заголовки приветствия (`Text`)
  * Поля ввода Email и пароля (`TextField`, `InputDecoration`, `Icons`)
  * Переключатель скрытия/отображения пароля (`obscureText`)
  * Ссылка «Забыли пароль?» (`TextButton`)
  * Кнопка подтверждения «Войти» (`ElevatedButton`)
  * Кнопки альтернативного входа через соцсети (Google, Apple, Телефон)
  * Ссылка на регистрацию нового аккаунта

### 2. Вкладка «Сложные макеты» (2 экрана)
* **Макет 3: Экран интернет-магазина / Каталога товаров (`CatalogScreen`)**
  * Шапка с иконкой корзины и счетчиком товаров (`Stack`, `Positioned`, `Badge`)
  * Поисковая строка с отдельной кнопкой вызова фильтра (`TextField`, `Row`)
  * Рекламный промо-баннер с градиентной заливкой (`Container`, `LinearGradient`, `BoxShadow`)
  * Горизонтальный скролл чипсов категорий (`SingleChildScrollView(scrollDirection: Axis.horizontal)`, `ChoiceChip`)
  * Список карточек товаров: название, описание, рейтинг, ценник и кнопка быстрого добавления в корзину (`Card`, `Row`, `Column`, `ElevatedButton`)
* **Макет 4: Экран статьи с комментариями и отзывами (`ArticleScreen`)**
  * Графический баннер в шапке публикации (`Container`, `LinearGradient`, `Icon`)
  * Бейджи тематических тегов статьи (`Wrap`, `Container`)
  * Полный заголовок статьи и блок информации об авторе с кнопкой подписки
  * Форматированный текст публикации (`Text` со стилизацией межстрочного интервала)
  * Интерактивный блок статистики: лайки, просмотры, комментарии (`Card`, `Row`, `Icon`)
  * Раздел отзывов с карточками комментаторов, датами и звездными рейтингами (`Card`, `CircleAvatar`, `Row`)
  * Поле для ввода и отправки нового комментария (`TextField`, `IconButton`)

## 🛠 Использованные виджеты Flutter

В ходе выполнения работы были изучены и применены следующие виджеты библиотеки `package:flutter/material.dart`:
* **Структура и компоновка**: `Scaffold`, `AppBar`, `BottomNavigationBar`, `Column`, `Row`, `Stack`, `Positioned`, `Expanded`, `Spacer`.
* **Контейнеры и отступы**: `Container`, `Padding`, `SizedBox`, `Card`, `Divider`.
* **Отображение контента**: `Text`, `Icon`, `CircleAvatar`, `Chip`, `ChoiceChip`.
* **Скроллинг**: `SingleChildScrollView`, `ListView`.
* **Формы и кнопки**: `TextField`, `ElevatedButton`, `OutlinedButton`, `TextButton`, `IconButton`.
* **Стилизация**: `BoxDecoration`, `BorderRadius`, `LinearGradient`, `BoxShadow`, `InputDecoration`, `TextStyle`.
